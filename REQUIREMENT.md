# Project Requirements: Cortex Systems Portfolio v2.0 (2026)

## 1. Project Vision & Brand Identity
**Brand Name:** Cortex Systems
**Identity:** Senior Fullstack Developer / Product Engineer
**Tagline:** Intelligent Experiences. Secure Infrastructure.
**Core Aesthetic:** Premium Navy (#0A192F) and Gold (#D4AF37) dashboard-style interface.

## 2. Target Audience
- **Technical Leaders (CTOs/EMs):** Looking for architectural reasoning and code quality.
- **Product Managers:** Seeking a developer who understands business value and UX trade-offs.
- **Recruiters:** Validating senior-level proficiency in React, Next.js, and Node.js ecosystems.

## 3. Grounded Developer Identity (Manifesto)
A dedicated section detailing my "Engineering Operating System":
- **Constraint-Driven Design:** How I build within boundaries like API limits and budget.
- **Architectural Pragmatism:** Choosing tools based on maintenance overhead and reliability.
- **Velocity vs. Quality:** Balancing MVP speed with scalable foundations (refactoring vs. rewriting).
- **Production Reasoning:** My "Trace-Log-Isolate" approach to debugging live systems.

## 4. Enhanced Project Narratives (Product Thinking)
Every major project (e.g., School Management System) must move beyond a list of features to include:
- **The Problem & Value:** Why the feature exists and the business problem it solved.
- **MVP Decisions:** What was prioritized for release and what was intentionally deferred.
- **Real-World Constraints:** How hosting (Vercel/Render) or API limits shaped the final build.
- **Architecture Trade-offs:** Documenting why one pattern was chosen over another (e.g., RSC vs. Client Components).

## 5. Live Proof of Work & Trust Signals
- **Pulse of the Engine:** Real-time GitHub activity integration (commits/contributions).
- **System Status Dashboard:** Live "Online/Offline" status for deployed production apps.
- **Project Lifecycle Tags:** Clear indicators of project status: 🟢 Maintained, 🟡 Stable, or 🧪 Experimental.
- **Direct Links:** One-click access to live deployments and clean, documented repositories.

## 6. AI Command Center (Navigation Layer)
A CMD+K natural language interface designed for developer productivity:
- **Discovery Queries:** "Show me projects with secure auth," or "What did you build with Next.js?"
- **Technical Summaries:** AI-generated "TL;DR" summaries of project architecture on demand.
- **Navigation Efficiency:** Improving user experience by allowing non-linear exploration of the portfolio.

## 7. Performance & Security Baseline
- **Performance Metrics:** Transparent Lighthouse scores and Core Web Vitals targets (100/100).
- **Security-Conscious Building:** Demonstrating standard professional practices (Zod validation, rate limiting, CSP headers) as part of a responsible fullstack workflow.

## 8. Technical Stack (2026 Standards)
- **Frontend:** Next.js 15+ (App Router), TypeScript (Strict), Tailwind CSS v4, Framer Motion.
- **Backend:** Next.js Server Actions / API Routes, Node.js.
- **Database/ORM:** PostgreSQL (Supabase/Neon), Drizzle or Prisma.
- **Workflow:** GitHub Actions (CI/CD), Vercel/Render deployment.
